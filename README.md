# OSINT Report Builder

## Запуск
Откройте `index.html` или запустите `python -m http.server 8000` и перейдите на `http://localhost:8000`.

## Обновление интерфейса
- добавлена нижняя навигация для телефонов;
- панели страниц, добавления и свойств открываются по запросу;
- лист автоматически подстраивается под ширину экрана;
- уменьшено количество кнопок в мобильной верхней панели;
- переработаны отступы и размеры сенсорных элементов;
- печать/PDF скрывает интерфейс редактора.

Проекты хранятся в localStorage браузера. Это клиентская первая версия; полноценный экспорт PDF, серверное хранение и продвинутые сенсорные манипуляторы можно добавить отдельным этапом.
